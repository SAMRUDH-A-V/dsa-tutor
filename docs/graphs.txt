GRAPHS

Graph:
A graph consists of vertices (nodes) and edges connecting them.

Types:
Directed graph: Edges have direction.
Undirected graph: Edges have no direction.
Weighted graph: Edges have weights.
Unweighted graph: Edges do not have weights.

Common representations:
1. Adjacency Matrix
2. Adjacency List

Common problems:
1. BFS
2. DFS
3. Number of Islands
4. Detect Cycle
5. Shortest Path

BFS:
Breadth First Search explores nodes level by level.

Use a Queue.

Time Complexity: O(V + E)
Space Complexity: O(V)

DFS:
Depth First Search explores as deeply as possible before backtracking.

Can be implemented using recursion or a Stack.

Time Complexity: O(V + E)
Space Complexity: O(V)

Number of Islands:
Treat the grid as a graph.
When an unvisited land cell is found, run BFS or DFS to visit the connected component.

Common mistakes:
1. Forgetting the visited array/set.
2. Confusing BFS and DFS.
3. Incorrectly handling graph boundaries.
4. Visiting the same node repeatedly.
5. Forgetting that disconnected graphs may have multiple components.

Hint progression:
Hint 1: How can you represent the connections between nodes?
Hint 2: Which data structure can help you explore level by level?
Hint 3: How can you mark a node as visited?
