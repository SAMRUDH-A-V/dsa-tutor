TWO POINTERS

Two Pointers:
Use two indices to process an array or string efficiently, often from opposite ends or from the same direction.

Common problems:
1. Two Sum II
2. Valid Palindrome
3. Remove Duplicates from Sorted Array
4. Container With Most Water

Two Sum II:
Given a sorted array, find two numbers that add up to a target.

Optimal approach:
Use left at the beginning and right at the end.
If the sum is too small, move left forward.
If the sum is too large, move right backward.
If the sum equals the target, the pair is found.

Time Complexity: O(n)
Space Complexity: O(1)

Container With Most Water:
Use two pointers at both ends.
Calculate the area and move the pointer with the smaller height.

Time Complexity: O(n)
Space Complexity: O(1)

Common mistakes:
1. Moving the wrong pointer.
2. Forgetting that the array must be sorted for some two-pointer techniques.
3. Using nested loops when two pointers can reduce complexity.
4. Moving both pointers unnecessarily.

Hint progression:
Hint 1: Can you process the array from both ends?
Hint 2: What does the current sum tell you about which pointer should move?
Hint 3: If the sum is smaller than the target, which pointer should move?
